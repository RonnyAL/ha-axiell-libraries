# Axiell Libraries 0.5.0

Version 0.5.0 improves recovery from provider failures and makes loan freshness
visible without requiring manual integration reloads.

- Recoverable failures get three early recovery cycles at 60, 120 and 240 seconds
  plus 0–25% jitter, then normal polling until success resets the budget.
- Respect HTTP `Retry-After`, including manual refreshes, entry reloads and read
  reconciliation after renewal. Security failures do not get accelerated retries.
- Distinguish transport, timeout, rate limit, server, session, credential,
  protocol and security failures with sanitized diagnostic references.
  Repeated session expiry no longer incorrectly requests a new PIN.
- Retain last-known loans during temporary failures with `data_stale`,
  `last_successful_refresh`, `last_update_error`, and a **Data freshness** sensor.
  Only a successful empty response displays zero loans. Freshness reports the
  last completed read; the timestamp shows its age.
- Add **Configure → Update interval (minutes)**: 30–1440 minutes, default 360.
  Existing installations retain six hours. Option changes apply without reload,
  another login, changed entity IDs or a new DeviceID.
- Allow account-authorized non-admin renewal while preserving permission checks,
  consent and account isolation. Polling and renewal stay serialized; renewal
  writes are never automatically repeated.

The November 15 outage's initiating cause remains unknown. The retained HA log
contains one generic failure without underlying exception details. This release
addresses verified recovery/diagnostic weaknesses without assuming session expiry
or network failure caused that incident.

Requires Home Assistant 2026.11.0 or later; target 2026.11.1 and Python 3.14.
The release workflow runs both supported Core/harness versions, the full offline
suite, Ruff and hassfest before publishing. Provider responses in automated tests
are synthetic; no live renewal or provider challenge sequence was tested.
See the [validation record](https://github.com/RonnyAL/ha-axiell-libraries/blob/v0.5.0/docs/validation.md)
for environment evidence and remaining live assumptions.

Restart Home Assistant after installing the update. Keep existing entries:
credentials, persistent DeviceIDs and existing entity IDs need no migration.
Cached snapshots and cooldowns remain in memory; a full HA restart clears them.
See the [user guide](https://github.com/RonnyAL/ha-axiell-libraries/blob/v0.5.0/README.md)
and [renewal guide](https://github.com/RonnyAL/ha-axiell-libraries/blob/v0.5.0/docs/home-assistant-ui.md#renew-one-loan).
