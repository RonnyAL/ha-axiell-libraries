Axiell Libraries 0.3.0 adds individual loan details to the existing read-only
Home Assistant integration.

- Active loans exposes a structured `loans` attribute for standard dashboards
  and automations, with separate loan IDs, subtitle/author, due dates,
  circulation status and optional bibliographic metadata.
- Rich loan attributes are excluded from Recorder while count history remains
  available. Existing three sensors and the read-only to-do list are retained.
- To-do descriptions include useful catalogue and circulation details. Direct
  HTTPS covers are optional; title and due text remain usable without images.
- Per-account catalogue caching preserves independent due dates/status for
  multiple copies and keeps loans visible when optional enrichment fails.
- Authentication retains the owner-verified bootstrap/session contract and
  persistent DeviceID, with safe setup failure references.
- Release validation checks canonical tag `v0.3.0` against numeric manifest
  `0.3.0`. Publication uses the validated main commit and these reviewed notes.

Requires Home Assistant 2026.11.0 or later; target 2026.11.1 and Python 3.14.
Restart Home Assistant after updating. See the
[dashboard guide](https://github.com/RonnyAL/ha-axiell-libraries/blob/v0.3.0/docs/home-assistant-ui.md)
for standard Markdown cards and structured attributes.

The owner has confirmed live authentication, all three aggregate sensors and
Marketplace installation/update. New structured dashboard rendering and browser
cover loading still require an owner-run check. Automated coverage is offline
with synthetic data; it does not demonstrate a live Solus refresh or published
Marketplace release installation. Library writes and renewals remain outside
this integration.
