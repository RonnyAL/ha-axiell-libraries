# Axiell Libraries 0.5.1

Fix catalogue body-status handling for exact session-expiry values
`sessionexpired` and `LOGINEXPIRED`, and unsupported validation value
`VALIDATIONREQUIRED`, including HTTP 200, before read or renewal response
decoding. Session recovery stays bounded; unsupported validation does not
trigger accelerated retries or PIN reauthentication. Renewal writes are
never automatically repeated, and uncertain outcomes require reconciliation.

Existing accounts, persistent DeviceIDs, entity IDs, polling options and
freshness reporting remain compatible. Restart Home Assistant after updating.
Requires Home Assistant 2026.11.0 or later; target 2026.11.1 and Python 3.14.

The publication workflow requires full offline validation on both supported
Home Assistant versions, Ruff and hassfest. Synthetic tests do not establish
live provider behavior or the initiating cause of the November 15 outage.
No live renewal or provider challenge sequence has been tested. See the
[validation record](https://github.com/RonnyAL/ha-axiell-libraries/blob/v0.5.1/docs/validation.md).
